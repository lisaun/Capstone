# Capstone
**Project Overview**

This repository documents the ongoing development of our capstone project, including the use of 3D environments and a mannequin model for project visualization.

**Current Progress**

Work completed so far includes:

- Selecting and working with existing 3D environments for the project.

- Visualizing the environments and mannequin.

- Adjusting positioning points to ensure proper alignment for the intubation procedure.

**Ongoing Development**

Our team is currently working on modelling the laryngoscope and endotracheal tube, as well as attempting to update the project's Unity version to support further development. Additional updates and project components will be documented as development continues.
